# 🍽️ Food & Beer Pairing

A web application built with **Node.js**, **Express**, and **EJS** that allows users to choose a meal and discover the beers that pair best with it.

## 🚀 Features

* Choose a meal from a list.
* Display beer recommendations based on the selected meal.
* Simple and user-friendly interface built with EJS.
* Express server to handle routing and page rendering.

## 🛠️ Technologies Used

* Node.js
* Express.js
* EJS
* HTML / CSS

## 📦 Installation

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Navigate to the project folder:

```bash
cd project-name
```

3. Install the dependencies:

```bash
npm install
```

4. Start the server:

```bash
npm start
```

5. Open your browser and visit:

```
http://localhost:xxxx
```
